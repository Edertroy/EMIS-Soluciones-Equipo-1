# EMIS Soluciones S.A.S.

## Proyecto

Sistema de Gestión Comercial para EMIS Soluciones S.A.S.

## Descripción del proyecto

El proyecto consiste en desarrollar una solución web orientada a facilitar la consulta y gestión de la información comercial de EMIS Soluciones S.A.S.

La aplicación permitirá organizar y consultar información relacionada con los productos ofrecidos por la empresa, facilitar la búsqueda de productos y apoyar la gestión de solicitudes de información realizadas por los clientes.

## Problema

EMIS Soluciones S.A.S. cuenta con un amplio portafolio de productos y servicios relacionados con construcción, ferretería, productos industriales, limpieza, cafetería, papelería y suministros de oficina.

El proyecto busca desarrollar una solución que permita organizar esta información y facilitar su consulta por parte de los clientes y la administración de la empresa.

## Producto

El producto será una aplicación web para la gestión y consulta de información comercial de EMIS Soluciones S.A.S.

Entre las funcionalidades planteadas se encuentran:

- Consulta del catálogo de productos.
- Búsqueda de productos.
- Filtrado de productos por categoría.
- Consulta del detalle de los productos.
- Registro y gestión de solicitudes de información.
- Administración de información comercial.
- Gestión de usuarios y roles.
