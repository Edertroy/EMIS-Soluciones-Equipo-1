# Sprint Review — Sprint 1

## Proyecto

Sistema de Gestión Comercial para EMIS Soluciones S.A.S.

## Equipo

**Equipo #1**

- Eder Avendaño
- Nicol Duque
- Cristian Zapata

## Objetivo del Sprint

Desarrollar la primera funcionalidad del sistema orientada a la consulta del catálogo de productos de EMIS, permitiendo visualizar, buscar, filtrar y consultar el detalle de los productos.

## Historias seleccionadas

Durante el Sprint 1 se seleccionaron las siguientes historias de usuario:

| ID | Historia de Usuario | Feature | Prioridad | Puntos |
|---|---|---|---|---:|
| US04 | Consultar catálogo de productos | F04 | Alta | 5 |
| US05 | Buscar productos | F05 | Alta | 5 |
| US06 | Filtrar productos por categoría | F06 | Media | 3 |
| US07 | Consultar información detallada de un producto | F07 | Media | 3 |

**Total estimado:** 16 puntos.

## Resultados esperados

Al finalizar el Sprint se espera contar con:

- Un catálogo de productos organizado.
- Una funcionalidad para consultar los productos disponibles.
- Una búsqueda de productos.
- Un filtro de productos por categoría.
- Una vista con información detallada de cada producto.
- Una primera versión funcional de la interfaz del sistema.

## Estado del Sprint

**Estado actual:** En planificación.

Las historias de usuario seleccionadas corresponden al alcance definido para el Sprint 1. La implementación y validación de estas funcionalidades se realizará durante el desarrollo del Sprint.

## Revisión

Durante la revisión del Sprint se verificará que las funcionalidades desarrolladas correspondan con las historias de usuario seleccionadas y sus respectivos criterios de aceptación.

También se revisará que los cambios realizados se encuentren registrados en el repositorio de GitHub mediante commits claros y organizados.

## Retroalimentación

La retroalimentación obtenida durante la revisión permitirá identificar ajustes, mejoras o nuevas necesidades que podrán incorporarse posteriormente al Product Backlog.

Una vez finalizado el Sprint 1:
