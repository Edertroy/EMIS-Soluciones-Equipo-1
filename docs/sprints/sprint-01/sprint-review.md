# Sprint Review — Sprint 1

## Proyecto

Sistema de Gestión Comercial para EMIS Soluciones S.A.S.

## Equipo

**Equipo #1**

- Eder Avendaño
- Nicol Duque

## Objetivo del Sprint

Desarrollar la primera funcionalidad del sistema orientada a la consulta del catálogo de productos de EMIS, permitiendo visualizar, buscar, filtrar y consultar el detalle de los productos.

## Historias seleccionadas

Durante el Sprint 1 se seleccionaron las siguientes historias de usuario:

| ID | Historia de Usuario | Feature | Prioridad | Puntos |
|---|---|---|---|---:|
| US04 | Consultar catálogo de productos | F04 | Alta | 5 |
| US05 | Buscar productos | F05 | Alta | 5 |
| US06 | Filtrar productos por categoría | F06 | Media | 3 |
| US07 | Consultar información detallada de un producto | F07 | Media | 3 |

**Total estimado:** 16 puntos.

## Resultados esperados

Al finalizar el Sprint se espera contar con:

- Un catálogo de productos organizado.
- Una funcionalidad para consultar los productos disponibles.
- Una búsqueda de productos.
- Un filtro de productos por categoría.
- Una vista con información detallada de cada producto.
- Una primera versión funcional de la interfaz del sistema.

## Estado del Sprint

## Estado del Sprint

**Estado:** Completado a nivel de implementación inicial.

Durante el Sprint 1 se desarrolló y probó una primera versión funcional de la aplicación web para consultar el catálogo de productos de EMIS Soluciones S.A.S.

Las funcionalidades implementadas y verificadas fueron:

* Consulta del catálogo de productos.
* Búsqueda de productos por nombre y descripción.
* Filtrado de productos por categoría.
* Consulta del detalle de cada producto.
* Visualización adaptable a diferentes tamaños de pantalla.

### Validación funcional

Se realizaron pruebas manuales de las funcionalidades principales de la aplicación y se comprobó su funcionamiento.

Las funcionalidades implementadas corresponden a las historias US04, US05, US06 y US07 seleccionadas para el Sprint 1.

La aplicación fue desarrollada utilizando HTML, CSS y JavaScript, y el proyecto se publicó en GitHub para mantener el código fuente y el historial de cambios.


## Revisión

Durante la revisión del Sprint se verificó el funcionamiento inicial de las funcionalidades desarrolladas.

Se comprobó que:

- El catálogo de productos se muestra correctamente.
- El usuario puede buscar productos mediante el campo de búsqueda.
- El usuario puede filtrar productos por categoría.
- El usuario puede consultar el detalle de un producto.
- La interfaz se adapta a diferentes tamaños de pantalla.

Las funcionalidades fueron implementadas utilizando HTML, CSS y JavaScript.

La revisión formal de los criterios de aceptación y el registro de los cambios mediante commits se realizará como parte del proceso de organización del repositorio.

## Retroalimentación

La primera versión permite identificar posibles mejoras para los siguientes Sprints.

Entre las mejoras que podrán considerarse se encuentran:

- Incorporar imágenes reales de los productos.
- Ampliar el catálogo de productos.
- Mejorar la información mostrada en el detalle de cada producto.
- Incorporar funcionalidades relacionadas con las solicitudes de información de los clientes.
- Incorporar funcionalidades de administración de la información comercial.
- Implementar posteriormente la gestión de usuarios y roles.

Estas mejoras podrán ser evaluadas y, de acuerdo con su prioridad, incorporadas al Product Backlog.
