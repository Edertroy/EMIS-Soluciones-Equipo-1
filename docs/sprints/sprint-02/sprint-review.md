
# Sprint Review — Sprint 2

## Proyecto

**Sistema de Gestión Comercial para EMIS Soluciones S.A.S.**

**Equipo:** Equipo 1

**Integrantes:**
- Eder Avendaño
- Nicol Duque
- Cristian Zapata

## Objetivo del Sprint

Implementar una funcionalidad que permita registrar nuevos productos en el catálogo comercial de EMIS Soluciones S.A.S.

## Historia desarrollada

**US01 — Registrar productos**

**Épica:** E1 — Gestión del catálogo de productos

**Feature:** F01 — Registrar productos

**Estimación:** 5 puntos

**Estado:** Completada

## Funcionalidades implementadas

- Formulario para registrar productos.
- Captura del nombre, categoría y descripción.
- Validación de los campos obligatorios.
- Confirmación del registro exitoso.
- Incorporación de los nuevos productos al catálogo.
- Compatibilidad con la búsqueda y el filtrado por categoría.
- Consulta del detalle de los productos registrados.

## Pruebas realizadas

Se probó el registro de productos y se verificó el funcionamiento de las funcionalidades relacionadas.

También se comprobó que los productos registrados desaparecen al recargar la página, de acuerdo con el alcance definido para este Sprint.

## Resultado del Sprint

El objetivo del Sprint se cumplió. La aplicación permite registrar productos temporalmente y consultar los nuevos registros mientras la página permanece abierta.

## Limitaciones

Los datos se almacenan únicamente en memoria. No se implementó una base de datos ni almacenamiento persistente.

## Estado final

La historia US01 se encuentra completada y la funcionalidad está integrada con el catálogo desarrollado en el Sprint 1.
